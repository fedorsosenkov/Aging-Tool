# MOS Aging Analyzer

Инструмент анализа деградации МОП-транзисторов по моделям **HCI** (горячие носители, NMOS) и **NBTI** (нестабильность порогового напряжения, PMOS) в связке с LTSpice.

## Установка

```bash
pip install PyQt6 numpy
```

## Запуск

```bash
cd aging_tool
python main.py
```

## Рабочий процесс (5 шагов)

### Шаг 1 — Загрузка netlist
Откройте схему в LTSpice → **View → SPICE Netlist** → сохраните как `.cir` или `.net`.
Загрузите файл в программу.

### Шаг 2 — Выбор транзисторов
Выберите МОП-транзисторы для анализа.
- **NMOS** → расчёт деградации по модели HCI
- **PMOS** → расчёт деградации по модели NBTI

### Шаг 3 — Подготовка симуляции
Программа создаёт `.inc` файл с командами `.measure` и B-источниками.
Скопируйте директиву `.include ...` и вставьте на схему в LTSpice (через `.op`).
Запустите симуляцию (**Simulate → Run**).

### Шаг 4 — Загрузка результатов
Загрузите **Spice Error Log** (`.log`) из папки схемы.
Укажите параметры: срок службы и |Vth| PMOS.
Нажмите «Рассчитать».

### Шаг 5 — Результаты
- **HTML-отчёт** с таблицами по каждому транзистору (открывается в браузере)
- **Постаревший netlist** (`_aged.cir`) и файл моделей (`models_aged.txt`)
  для повторной симуляции с учётом деградации

## Физические модели

Математическое описание - `math_models.md`

### HCI (NMOS)
```
ΔVth = 1.3 · 0.22 · |Id_max/W · (I_hci/Id_max)² · t_life · ratio|^0.27
```

### NBTI (PMOS)
```
ΔVth = 0.7 · (Kv · √(ratio · 2 · t_life))^(1/3)
```

Коэффициент снижения подвижности (для параметра u0 модели):
```
factor = 1 + 0.24·10⁻¹⁶ · (ΔVth · Cox / q)
```
